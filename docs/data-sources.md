# 可用資料集清單（「用不了」子題）

2026/11/07 在四個平台實際查過名稱。**欄位與 API 細節使用前要再打一次確認**，用了就搬進 README 的資料來源表。

## TDX（tdx.transportdata.tw，需金鑰）
| API | 用途 | 已確認欄位 |
|---|---|---|
| `/v2/Bus/EstimatedTimeOfArrival/City/Taipei` (N1) | 公車預估到站 | — |
| `/v2/Bus/RealTimeNearStop/City/Taipei` (A2) | 公車動態定點（含車牌） | — |
| `/v2/Bus/Vehicle/City/Taipei` | 公車車輛資料 | `IsLowFloor`（0/1）、`VehicleType`（1 一般／2 復康巴士…） |
| `/v2/Bus/Station/City/Taipei` | 公車站位 | — |
| Metro `StationExit`（TRTC） | 捷運出口 | `Elevator`、`Escalator`、`Stair` |
| Metro `StationFacility`（TRTC） | 捷運站內設施 | `Elevators`、`Toilets` |

A2 的車牌 join Vehicle 的 `IsLowFloor`，就能知道「快到站的這班是不是低地板」。
